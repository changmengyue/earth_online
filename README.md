# 地球online · 系统终端

> `> 地球online提示：`
>
> 一个用终端界面包装人生的单文件网页。

把「人生」当成一款正在运行的游戏，用**复古 CRT 终端**的视觉语言，把进度、任务、状态和成就一次性推送到你面前。

整个项目**只有一个 HTML 文件，零依赖、零构建、零后端**——双击即玩。

## 项目简介

打开页面，你会看到一块虚构的「地球online」系统终端在自检启动，然后依次推送六条消息：

| 推送内容 | 呈现形式 |
| --- | --- |
| 人生进度 | 环形进度表，`20%` |
| 辅助系统 | 红色警告：已终止（独立模式已激活） |
| 特殊任务（12年教育） | 进度条，已完成 `100%` |
| 父母的陪伴 | 进度条，已完成 `80%` |
| 完整地图 | 140×140 小地图 + 打字机文字「自由探索」 |
| 祝福 | `【祝您好运！】` + 进入成就殿堂入口 |

看完全部推送后，可以进入「成就殿堂」，在 25 个成就里逐一点亮属于自己的那一格。

**它不是一个应用，更像一件能打开的小作品。**

## 快速开始

不需要安装任何东西，不需要联网。

```bash
git clone git@github.com:changmengyue/earth_online.git
```

然后直接用浏览器打开仓库中的网页文件即可：

```
earth-online1.1.html
```

也可以拖拽到浏览器窗口，或在文件管理器里双击。

> 提示：解锁进度保存在浏览器 `localStorage` 中，关闭页面不会丢失；清除浏览器数据会一并清空。

## 页面内容

### 四角 HUD

终端四个角常驻状态信息，营造「正在被某个系统监控」的临场感：

- 左上：`SYS: EARTH-ONLINE v3.7.1`
- 右上：UTC 实时时钟（每秒刷新）、`NODE #0x7F3A-CN`
- 左下：`SIGNAL 87%`、`LAT 31.23°N`
- 右下：`FPS 60`、`LON 121.47°E`

### 启动日志

五行逐条浮现的引导日志，从「系统初始化中」到「校准时空坐标 [OK]」，作为整段叙事的开场。

### 进度与状态

- **人生进度**：SVG 环形进度表，动画增长至 `20%`
- **辅助系统已终止**：`Auxiliary System: OFFLINE — 独立模式已激活`
- **特殊任务（12年教育）已完成**：进度条 `100%`
- **父母的陪伴已完成**：进度条 `80%`

### 小地图

`<canvas>` 绘制的地图与光点，配打字机效果循环输出文字「自由探索」。

### 成就殿堂

点击「▸ 走进成就殿堂」，进入覆盖式成就墙：

- **玩家档案**：汇总人生进度、特殊任务、辅助系统、父母陪伴四项状态，并显示当前玩家称号与总进度条
- **分类选项卡**：日常 / 社交 / 工作·学习 / 人生 / 彩蛋，每类显示 `已解锁/总数`
- **成就卡片**：点击展开详情并解锁，附音效与解锁提示条

### 存档与称号

- 解锁状态通过 `localStorage` 持久化，刷新页面进度不丢
- 提供 `loadUnlockedIds()` / `saveUnlockedIds()` 读写存档
- 根据解锁数量动态授予玩家称号（`getPlayerTitle`），档案面板与成就墙同步刷新
- 解锁时播放 Web Audio 合成的提示音（`playUnlockSound`），无外部音频文件

## 技术实现

**纯原生技术栈**：HTML + CSS + JavaScript（ES6），无框架、无库、无 CDN、无构建步骤。

### CSS：全部视觉氛围

- 主题色与光晕以 CSS 自定义属性集中在 `:root`，改色只需改一处
- CRT 质感由多层叠加实现：扫描线（`repeating-linear-gradient` + 位移动画）、晕影（`radial-gradient`）、闪烁层、故障艺术覆盖层（glitch overlay）
- 终端等宽字体栈：`Courier New / Consolas / Monaco / Liberation Mono`

### JavaScript：动画与交互

- **星空背景**：`<canvas>` 绘制星点，随窗口尺寸自适应
- **小地图**：光点初始化 + 逐帧绘制，营造雷达扫描感
- **动画引擎**：数字滚动计数、SVG 环形进度、进度条填充、打字机输出
- **渲染循环**：单一 `requestAnimationFrame` 主循环统一驱动，按帧间隔判断节流
- **故障效果**：`scheduleGlitch()` 随机调度触发，避免高频干扰
- **入场控制**：`reveal()` 按时间线依次揭示各区块
- **成就模块**：卡片动态渲染、点击解锁、Toast 提示、选项卡切换

### 性能取舍

代码中保留了明确的性能优化痕迹，随手可查：

- 星星数量逐级下调：`160 → 80 → 60`
- CRT 闪烁动画从 `0.15s` 放慢到 `4s`，显著降低高频重绘
- 对频繁重绘的 canvas 声明 `will-change: contents`，提示浏览器合成层优化

### 数据与状态

- 成就定义、分类映射以纯数据结构维护在数组/对象中，**新增成就只需增加一条数据**，无需改动渲染逻辑
- 无任何网络请求，完全离线可用

## 项目结构

```text
earth_online/
├── earth-online1.1.html   # 全部内容：样式 + 结构 + 逻辑（单文件，约 2091 行）
├── README.md              # 本文件
└── .git/
```

单文件内部按三段组织，便于定位：

| 行号范围 | 内容 |
| --- | --- |
| `1 – 1068` | `<style>` — 约 1060 行 CSS，变量、氛围层、组件样式 |
| `1069 – 1269` | HTML 骨架 — HUD、启动日志、各推送区块、成就殿堂 |
| `1270 – 2091` | `<script>` — 约 820 行原生 JS，IIFE 封装，`'use strict'` |

> 设计上刻意保持单文件：方便直接分享、离线打开、单页存档，也便于按时间线回溯每一版的差异。

## 版本沿革

项目在迭代中以 `1.0 → 1.1 → 1.2 → 1.2c → 1.2g` 命名推进，仓库当前收录的是对外发布的通用版本：

| 版本 | 文件 | 说明 |
| --- | --- | --- |
| 1.0 | — | 早期骨架版，内容大体成型 |
| 1.1 | `earth-online1.1.html` | 当前仓库收录版本，标题已通用化 |
| 1.2 / 1.2c / 1.2g | — | 后续在本地继续完善，1.2g 为当前最新 |

当前仓库中 `earth-online1.1.html` 的实际代码内容与迭代序列中最新的版本一致，**仅标题文案做了通用化处理**（去掉了面向具体个人的称呼）。文件名保留 `1.1` 是为了沿用既有标签，内容以实际文件为准。

## 浏览器兼容

项目使用 `canvas`、`SVG`、`requestAnimationFrame`、`localStorage` 与 Web Audio：

- 推荐使用 **Chrome / Edge / Firefox / Safari 的较新版本**
- 无需服务器，`file://` 直接打开即可运行
- 若浏览器禁用 `localStorage`（如部分隐私模式），成就进度将无法保存，但页面功能本身不受影响
